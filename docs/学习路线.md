# 视频点播项目：一起动手学习

这份路线用于在参考实现完成后，按小步骤重新编写和测试。建议在独立练习目录操作，保留参考项目和现有数据库；遇到错误时先看完整报错，不要直接覆盖参考实现。

## 开始之前

项目的服务端运行在 Linux 开发容器中，主要使用 C++17、CMake、Protobuf、BRPC、MySQL、etcd、FastDFS、FFmpeg 和 RabbitMQ；客户端使用 Qt 6 和 libmpv。各组件职责和接口边界比一次记住全部代码更重要。

先确认目录和构建结果：

```sh
cd /home/dev/workspace/vod-platform
cmake -S . -B build -DVOD_BUILD_CLIENT=ON
cmake --build build --parallel 1
ctest --test-dir build --output-on-failure
```

集成测试需要额外的临时测试依赖；仅凭默认测试成功不能推断全部服务可用。项目根目录 `README.md` 说明了依赖和测试开关。

## 建议顺序

1. **CMake 和目录结构。** 阅读 `CMakeLists.txt`、`include/`、`src/`、`tests/`；画出一个可执行文件、库和依赖之间的关系。练习为领域规则添加一个小的独立函数并编译调用。
2. **视频状态和输入校验。** 阅读 `include/vod/domain/video.h` 和 `src/domain/video.cpp`，画出处理中、待审核、已发布、驳回、下架和删除的状态变化；用 `tests/video_test.cpp` 验证不能发生的状态转换。
3. **服务发现和 RPC。** 阅读 `proto/`、`src/rpc/`、`src/rpc/health_server.cpp` 与 `health_client.cpp`，先讲清请求、响应、注册和发现，再实现一个健康检查。
4. **数据库与会话。** 阅读 `sql/001_sessions.sql`、`sql/003_accounts.sql` 和 `src/user/session_store.cpp`。练习访客登录、过期检查、退出和非法会话处理。
5. **邮箱与账号。** 阅读 `src/user/verification_store.cpp`、`smtp_sender.cpp`、`account_store.cpp`。区分验证码的生成、保存、校验、失效，以及密码验证；先用测试邮件服务练习，避免发送真实邮件。
6. **HTTP 网关。** 阅读 `src/gateway/main.cpp` 和 `proto/user.proto`，追踪一个登录请求经过 HTTP、RPC、数据库后返回的过程。练习校验必填字段和处理服务不可用。
7. **文件上传和权限。** 阅读 `src/file/` 与 `scaffold/src/fdfs.cc`，理解文件内容存储、数据库记录、文件所有权、公开视频和未审核视频的区别。
8. **视频提交和消息队列。** 阅读 `src/video/video_store.cpp`、`src/mq/wakeup.cpp`、`sql/002_videos.sql`。先理解视频和待转码任务为什么要同时写入数据库，再理解消息只是唤醒提示。
9. **转码与审核。** 阅读 `src/transcode/`，从一个视频跟踪到 HLS 播放列表和分片，再验证审核前后的访问权限和下架操作。
10. **搜索、互动和管理。** 阅读视频分类、标签、点赞、弹幕、关注及管理员相关接口，分别练习一条成功路径和一条越权路径。
11. **Qt 客户端。** 阅读 `client/main.cpp`，从按钮点击追踪 JSON 请求和界面更新；再理解 libmpv 播放、进度和错误处理。
12. **联调与复盘。** 从登录、上传、转码、审核到播放走一遍；阅读 `tests/run_mysql_test.py`、`tests/run_client_ui_test.py`、`tests/run_supervisor_test.py`，解释每项验证覆盖的行为和未覆盖的环境。

每一阶段都先理解输入和输出，再自己写一个最小版本，运行测试并讨论错误。Windows 客户端打包、长期运行的部署环境和生产环境可靠性仍需单独验证，不能把容器里的无界面测试当作这些事项的验收。
